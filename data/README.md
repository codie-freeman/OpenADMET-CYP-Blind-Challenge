# data/

**No blind-set labels exist anywhere in this repo, in any form.** Every leaderboard score cited in
this project (`docs/leaderboard_submissions.md`) came from OpenADMET's own leaderboard after a real
submission, never from a locally-held answer key. `data/raw/cyp-challenge-TEST-BLINDED.csv`
contains only compound identifiers and SMILES — no activity columns.

`data/raw/` and `data/processed/` are gitignored (tracked only via their own `PROVENANCE.md`/this
file) — a fresh clone must regenerate both by running the notebooks in order; see the root
`README.md`'s Quick Start.

## `raw/` — untouched HuggingFace release

Source: https://huggingface.co/datasets/openadmet/cyp-challenge-train-test, pinned revision
`85f8b358d0a2056a98b990dd75d3b3ec9247862b` (downloaded 2026-08-19). See `raw/PROVENANCE.md` for the
full download record and re-download instructions. No cleaning, filtering, or modification was
applied to any of these files — they are byte-identical to what HuggingFace served.

| File | Rows | Notes |
|---|---|---|
| `cyp-challenge-TRAIN_inhibition.csv` | 4,905 | The Direct Inhibition track's real training data — in scope. |
| `cyp-challenge-TEST-BLINDED.csv` | 750 | The blind test set — compound identifiers/SMILES only, no labels. |
| `cyp-challenge-TRAIN_TDI.csv` | 6,145 | Time-dependent-inhibition data. Its `direct_inhibition` columns are byte-identical to `TRAIN_inhibition.csv` (notebook `00`'s finding) — out of scope for this track except as an auxiliary-head source (notebook `22`). |
| `cyp-challenge-TRAIN_Emax.csv` | 6,146 | Emax data — out of scope for this track except as an auxiliary-head source (notebook `22`). |
| `cyp-challenge-single-concentration-TRAIN.csv` | 17,504 | Single-concentration primary screen — out of scope for direct training; used only as log2fc pretraining data (`03b`) and checked for compound-pool overlap (`23`, found to add zero new compounds). |

`raw/aid1851/` — PubChem AID 1851 (NCATS qHTS cytochrome panel), fetched by
`scripts/13_fetch_aid1851.py` for notebook `13`. Used strictly as an **external population-moment
estimate** for blind-set calibration experiments (notebooks `13`/`14`) — never as training or
fine-tuning data. Batched CSVs (`batch_0000.csv`–`batch_0008.csv`) plus `combined_raw.csv`,
`description.json`, `reference_compound_cids.json`, `sids.json`, and a `_FETCH_COMPLETE` marker.

## `folds/` — frozen split assignments

- **`cv_folds.csv`** — the frozen 5×5 repeated-CV fold assignment (`RepeatedKFold`, seed 42),
  written once by notebook `03` and never touched again. Every CV comparison in this project
  (`05` and its variants) reads this file read-only.
- **`analog_holdout_split.csv`** — a single train/test partition approximating the real blind
  set's construction (notebook `15`), kept alongside `cv_folds.csv`, not replacing it.

Notebook `05b`'s own cluster-aware CV split lives under `outputs/05b_cluster_cv_comparison/
cluster_cv_folds.csv`, not here — it was built as a new output rather than a new frozen input.
